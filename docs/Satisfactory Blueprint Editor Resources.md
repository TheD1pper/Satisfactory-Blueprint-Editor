`CommunityResources/` under the game install ships an Epic-provided modding SDK with everything needed to reverse the `.sbp` blueprint format:

- **`Headers/Source/FactoryGame/Public/FGFactoryBlueprintTypes.h`** — exact struct layout of a blueprint file: `FBlueprintHeader` (SaveVersion, BuildVersion, Dimensions, Cost, Recipes; version enum `InitialVersion`→`AddedItemCosts`→`AddedUsedRecipes`) and `FBlueprintSaveData` (= header + raw `TOCData` + raw `BlobData` byte arrays). Has `friend FArchive& operator<<` showing serialization order.
- **`BlueprintArchiveObjectTOCProxy.h` / `BlueprintArchiveObjectDataProxy.h` / `BlueprintObjectReaderFName.h`** — the `FArchiveProxy` classes the game uses to write TOC (object name/class/transform + redirectors) and Blob (bulk UPROPERTY data) sections.
- **`FGSaveSession.h`** — `FSaveObjectVersionData` struct (PackageFileVersion, EngineVersion, CustomVersionContainer) written ahead of object data in newer save/blueprint versions.
- **`CustomVersions.json`** (UTF-16 encoded, use `Get-Content -Encoding Unicode` in PowerShell) — live version numbers for the currently installed build: `"SaveVersion": 60`, `"Dev-Blueprints": 10` (GUID `B0D832E4-1F89-4F0D-ACCF-7EB736FD4AA2`). Maps directly to the version enums above.
- **`Docs/en-US.json`** (+ ~30 other locales) — the community-standard "Docs.json" game-data dump: every buildable/item/recipe class by `NativeClass`/`ClassName` with all properties as strings (`mDisplayName`, `mDescription`, icons, stack size...). Use to turn raw class names found in a blueprint's TOC (e.g. `Build_ConveyorBeltMk1_C`) into human-readable names/icons for the editor UI.
